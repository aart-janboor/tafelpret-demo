# Tafelpret 🐾 — publieke demo

Publieke demo-site van **Tafelpret**: een tablet-app waarmee kinderen (±9 jaar) de
tafels van 1 t/m 12 leren met een schattig huisdierthema en gamification (munten
verdienen, je huisdier voeren/verzorgen, kleertjes kopen).

👉 **Bekijk de klikbare mockup en het voorstel:** https://aart-janboor.github.io/tafelpret-demo/

Deze repo bevat alleen de mockup, screenshots en het voorstel, zodat GitHub Pages
het publiek kan tonen. De ontwikkeling gebeurt in een aparte (private) repo.

## Inhoud

- `index.html` — landingspagina (mockup-knop + screenshots + voorstel)
- `mockups/web-prototype/` — de klikbare mockup (HTML/CSS/JS)
- `mockups/screenshots/` — screenshots van alle schermen
- `PROPOSAL.md` — voorstel voor de Flutter-opzet
